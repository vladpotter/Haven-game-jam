# Eugene Quest
## a game by Connor Webb, Micheal Lueck, and Arjun Sankar (Creativity Assessor) 

We made a cool game about a cool circle named Eugene who like to climb mountain. He will climb Terrance Mountain. He MUST climb Terrance Mountain.

Link to great game: https://vladpotter.itch.io/eugene-quest

This game was made in Godot in Haven Game Jam (The theme was bounce back). This was our first game, but it's still a masterpiece, and it will beat GTA VI for Game o f The Year.
We were originally going to add a boss fight but there was no time, but we will still win Game of The Year.
